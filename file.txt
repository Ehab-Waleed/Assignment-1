2. What is hoisting and what is the Temporal Dead Zone (TDZ)? Explain with examples.

                                                // *********************************** //

ال hoisting هي خاصية في ال js معناها الرفع يعني ال js اول ما تيجي تعمل run لاي كود بترفع كل ال declarations فوق في اول الكود 
زي مثلا لو عندي متغير اسمه var x = 5 ال js بتاخد ال declaration  اللي هو var x وترفعه فوق في اول الكود ولو جيت استدعيته قبل السطر اللي معموله فيه initialization بيرجعلي undefined عكس ال let and const بيحصلهم برضو hoisting ولكن لو جيت استدعيهم قبل السطر اللي معمولهم فيه initialization هيرجعلي ايرور Cannot access x before initialization ودا بسبب وجودهم في TDZ 
- ال Temporal Dead Zone (TDZ) دي عباره عن المنطقه اللي بيكون فيها ال let and const معمولهم hoisting ولكن لسه متعملهمش initialization عشان كده لما باجي استدعيهم مبيقدرش وبيطلعلي ايرور
